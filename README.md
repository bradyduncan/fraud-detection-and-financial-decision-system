# fraud-detection-and-financial-decision-system
Intelligent Fraud Detection and Financial Decision Systems Using Ensemble Learning

## Setup Instructions
### Windows
Run the PowerShell init function `.\init.ps1` to install all dependencies.
### Mac
Run `make init` in the terminal. If `make` is not found, install Xcode Command Line Tools:
`xcode-select --install`
### Linux
Run `make init` in the terminal.
### Other Options
Create your own virtual python environment and run `pip install -r requirements.txt`.
